# Phoenix

**Personal finance, organized your way.**

Phoenix is a desktop personal finance application designed to make everyday
money management simple, clear, and organized.

Track your expenses and income, manage budgets and projects, attach receipts,
and understand where your money goes through analytics and financial insights.

---

## Download Phoenix

The latest desktop release is available for Windows, Linux, and macOS.

### Windows

Download:

**`Phoenix.exe`**

Run the installer and follow the installation steps.

### Linux

Download:

**`Phoenix-1.0.2-x86_64.AppImage`**

Make it executable and launch it:

    chmod +x Phoenix-1.0.2-x86_64.AppImage
    ./Phoenix-1.0.2-x86_64.AppImage

### macOS — Apple Silicon

For Macs with Apple Silicon:

**`Phoenix-1.0.2-arm64.dmg`**

### macOS — Intel

For Intel-based Macs:

**`Phoenix-1.0.2-x64.dmg`**

## What can Phoenix do?

Phoenix brings your personal finances together in one application.

- Track expenses and income
- Organize transactions with categories and tags
- Manage budgets
- Track projects
- Attach and manage receipts
- Analyze spending over time
- View financial insights and projections
- Track product price history
- Use Phoenix as a native desktop application

## Email verification

After registering, Phoenix sends an email verification message.

If the email does not appear in your inbox, check your **Spam** or **Junk**
folder.

For best delivery reliability, using a non-ABV email address is currently
recommended.

Email delivery can depend on the receiving mail provider and its spam,
reputation, and filtering policies.

## Verify your download

Every official Phoenix release includes a **`SHA256SUMS`** file.

On Linux, downloaded files can be verified with:

    sha256sum -c SHA256SUMS

A successful verification confirms that the downloaded file matches the
artifact published with the official Phoenix release.

SHA-256 verifies file integrity. Platform code signing and macOS notarization
are separate authenticity mechanisms.

## About the other files

GitHub Releases may contain additional files used internally by Phoenix for
automatic updates, including:

- `latest.yml`
- `latest-linux.yml`
- `.blockmap`
- macOS `.zip` packages

Most users do not need to download these files manually.

GitHub also automatically provides **Source code (zip)** and
**Source code (tar.gz)** for each release tag. These archives are generated
automatically by GitHub and are not Phoenix installers.
